LayerNorm

Normalise each example's features to mean 0 and variance 1, then let the network rescale them.

What it does

For each row (one example, or one token in a transformer), LayerNorm subtracts the row's mean and divides by its standard deviation, so the row has mean 0 and variance 1. Then a learnable scale \(\gamma\) and shift \(\beta\), one per feature, let the network undo or adjust that wherever it helps.

Used for: keeping activations at a steady scale through a deep network, which makes training much more stable. In a transformer there's one before attention and one before the MLP in every block (“pre-LN”), and one at the end before the output layer.

Each row is normalised on its own, so it works the same at any batch size, unlike BatchNorm, which normalises each feature across the batch.

Forward

For one row \(x = (x_1, \dots, x_D)\):

\[ \begin{aligned} \mu &= \frac{1}{D} \sum_{j=1}^{D} x_j && \text{mean} \\ \sigma^2 &= \frac{1}{D} \sum_{j=1}^{D} (x_j - \mu)^2 && \text{variance (biased: divide by } D\text{)} \\ \hat{x}_i &= \frac{x_i - \mu}{\sqrt{\sigma^2 + \epsilon}} && \text{normalised} \\ y_i &= \gamma_i\, \hat{x}_i + \beta_i && \text{scale and shift} \end{aligned} \]

\(\epsilon\) (around \(10^{-5}\)) stops a division by zero when every \(x_j\) in the row is equal. \(\gamma\) starts at 1 and \(\beta\) at 0, so a new LayerNorm is a plain normalisation.

Cache: \(\hat{x}\), \(1/\sqrt{\sigma^2 + \epsilon}\) and \(\gamma\). That's everything the backward pass needs.

Gradients: the result

\[ \frac{\partial L}{\partial \hat{x}_i} = \frac{\partial L}{\partial y_i}\, \gamma_i \] \[ \frac{\partial L}{\partial x_i} = \frac{1}{\sqrt{\sigma^2 + \epsilon}} \left( \frac{\partial L}{\partial \hat{x}_i} \;-\; \frac{1}{D} \sum_{j=1}^{D} \frac{\partial L}{\partial \hat{x}_j} \;-\; \hat{x}_i \cdot \frac{1}{D} \sum_{j=1}^{D} \frac{\partial L}{\partial \hat{x}_j}\, \hat{x}_j \right) \] \[ \frac{\partial L}{\partial \gamma_i} = \sum_{\text{rows}} \frac{\partial L}{\partial y_i}\, \hat{x}_i \qquad\qquad \frac{\partial L}{\partial \beta_i} = \sum_{\text{rows}} \frac{\partial L}{\partial y_i} \]

In words: take the gradient arriving at \(\hat{x}\), subtract its mean, subtract \(\hat{x}\) times the mean of (that gradient \(\times\, \hat{x}\)), and scale by \(1/\text{std}\).

Derivation

Shorthand for this section, all within one row:

\[ s = \sqrt{\sigma^2 + \epsilon} \qquad\qquad g_i = \frac{\partial L}{\partial \hat{x}_i} \]

Two facts get used repeatedly. The deviations from the mean sum to zero, and \(\partial x_j / \partial x_i\) is the Kronecker delta:

\[ \sum_{j} (x_j - \mu) = \sum_j x_j - D\mu = 0 \qquad\qquad \frac{\partial x_j}{\partial x_i} = \delta_{ij} = \begin{cases} 1 & i = j \\ 0 & i \ne j \end{cases} \]

γ and β

\(y_i = \gamma_i \hat{x}_i + \beta_i\) is element-wise, so \(\partial y_i / \partial \gamma_i = \hat{x}_i\) and \(\partial y_i / \partial \beta_i = 1\). \(\gamma\) and \(\beta\) are shared by every row (broadcast), so their gradients sum over rows.

Into x̂

Also element-wise: \(\partial y_i / \partial \hat{x}_i = \gamma_i\), so \(g_i = \dfrac{\partial L}{\partial y_i}\, \gamma_i\).

Through x̂ to x

This is the hard part, because \(x_i\) affects every \(\hat{x}_j\) in its row, through \(\mu\) and \(\sigma^2\). By the multivariable chain rule:

\[ \frac{\partial L}{\partial x_i} = \sum_{j=1}^{D} g_j\, \frac{\partial \hat{x}_j}{\partial x_i} \]

So we need \(\partial \hat{x}_j / \partial x_i\) for every pair \(i, j\). Build it up in pieces.

  1. The mean. Only the \(j = i\) term of the sum contains \(x_i\):

    \[ \frac{\partial \mu}{\partial x_i} = \frac{1}{D} \qquad\Longrightarrow\qquad \frac{\partial (x_j - \mu)}{\partial x_i} = \delta_{ij} - \frac{1}{D} \]

  2. The variance. Chain rule on each square, using step 1 for the inside:

    \[ \begin{aligned} \frac{\partial \sigma^2}{\partial x_i} &= \frac{1}{D} \sum_k 2(x_k - \mu) \left(\delta_{ki} - \frac{1}{D}\right) \\ &= \frac{2}{D} \left( (x_i - \mu) - \frac{1}{D} \sum_k (x_k - \mu) \right) \\ &= \frac{2}{D}\, (x_i - \mu) \end{aligned} \]

    The \(\delta_{ki}\) picks out the \(k = i\) term, and the remaining sum of deviations is 0.

  3. One over the standard deviation. \(1/s = (\sigma^2 + \epsilon)^{-1/2}\). Power rule, then chain rule with step 2:

    \[ \begin{aligned} \frac{\partial}{\partial x_i}\, \frac{1}{s} &= -\frac{1}{2} (\sigma^2 + \epsilon)^{-3/2} \cdot \frac{\partial \sigma^2}{\partial x_i} \\ &= -\frac{1}{2s^3} \cdot \frac{2}{D}\, (x_i - \mu) \\ &= -\frac{x_i - \mu}{D\, s^3} \end{aligned} \]

  4. The normalised value. \(\hat{x}_j = (x_j - \mu) \cdot \frac{1}{s}\) is a product, so use the product rule with steps 1 and 3:

    \[ \begin{aligned} \frac{\partial \hat{x}_j}{\partial x_i} &= \frac{1}{s}\left(\delta_{ij} - \frac{1}{D}\right) + (x_j - \mu) \cdot \left(-\frac{x_i - \mu}{D\, s^3}\right) \\ &= \frac{1}{s} \left( \delta_{ij} - \frac{1}{D} - \frac{1}{D} \cdot \frac{x_j - \mu}{s} \cdot \frac{x_i - \mu}{s} \right) \\ &= \frac{1}{s} \left( \delta_{ij} - \frac{1}{D} - \frac{1}{D}\, \hat{x}_i\, \hat{x}_j \right) \end{aligned} \]

    Pulling \(1/s\) out leaves \(1/s^2\) in the last term, which is exactly what turns both deviations into \(\hat{x}\)s.

  5. Sum over \(j\). Substitute step 4 into the chain rule and split the sum into its three terms:

    \[ \begin{aligned} \frac{\partial L}{\partial x_i} &= \sum_j g_j \cdot \frac{1}{s} \left( \delta_{ij} - \frac{1}{D} - \frac{1}{D}\, \hat{x}_i\, \hat{x}_j \right) \\ &= \frac{1}{s} \left( \sum_j g_j\, \delta_{ij} \;-\; \frac{1}{D} \sum_j g_j \;-\; \hat{x}_i \cdot \frac{1}{D} \sum_j g_j\, \hat{x}_j \right) \\ &= \frac{1}{s} \left( g_i \;-\; \frac{1}{D} \sum_j g_j \;-\; \hat{x}_i \cdot \frac{1}{D} \sum_j g_j\, \hat{x}_j \right) \end{aligned} \]

    \(\hat{x}_i\) doesn't depend on \(j\), so it comes out of the third sum, and \(\delta_{ij}\) picks \(g_i\) out of the first. Putting back \(s = \sqrt{\sigma^2 + \epsilon}\) and \(g = \partial L / \partial \hat{x}\) gives the result.

Why it gets messy by hand: the usual alternative is to backprop through the computation graph node by node (\(x \to \mu\), \(x \to \sigma^2\), \(\mu \to \sigma^2\), …), adding up the paths. It reaches the same answer, but the \(x \to \mu \to \sigma^2\) path and the direct \(x \to \sigma^2\) path have to be combined, and the cancellation from \(\sum_j (x_j - \mu) = 0\) is easy to miss. Going straight for \(\partial \hat{x}_j / \partial x_i\) keeps it to five steps.

Sanity checks

The result is the incoming gradient with two components removed:

  • \(\sum_i \partial L / \partial x_i = 0\). Adding a constant to every \(x_i\) doesn't change \(\hat{x}\), so it can't change the loss: the gradient can have no component along \((1, 1, \dots, 1)\). That's the \(-\text{mean}(g)\) term. (Check: sum the bracket over \(i\), using \(\sum_i \hat{x}_i = 0\).)
  • \(\sum_i \hat{x}_i\, \partial L / \partial x_i \approx 0\). Scaling the row's deviations up doesn't change \(\hat{x}\) either (exactly, when \(\epsilon = 0\)), so there's no component along \(\hat{x}\). That's the \(-\hat{x}\,\text{mean}(g \hat{x})\) term.
  • If every \(x_i\) in a row is equal, \(\hat{x} = 0\) and the gradient is \(\frac{1}{\sqrt{\epsilon}}\bigl(g_i - \text{mean}(g)\bigr)\): large, but finite, thanks to \(\epsilon\).

In code

def layernorm_forward(x, gamma, beta, eps=1e-5):
    mean = x.mean(axis=1, keepdims=True)
    x_centred = x - mean
    var = (x_centred * x_centred).mean(axis=1, keepdims=True)
    sd_inv = 1.0 / np.sqrt(var + eps)
    x_hat = x_centred * sd_inv
    return x_hat * gamma + beta, (x_hat, sd_inv, gamma)


def layernorm_backward(dout, cache):
    x_hat, sd_inv, gamma = cache
    dx_hat = dout * gamma
    mean_dx_hat = dx_hat.mean(axis=1, keepdims=True)
    mean_dx_hat_x_hat = (dx_hat * x_hat).mean(axis=1, keepdims=True)
    dx = sd_inv * (dx_hat - mean_dx_hat - x_hat * mean_dx_hat_x_hat)
    dgamma = (dout * x_hat).sum(axis=0)
    dbeta = dout.sum(axis=0)
    return dx, dgamma, dbeta

Statistics are over the row (axis=1, with keepdims so they broadcast back); parameter gradients sum over the rows (axis=0).
