Math

The bits of school and university maths that keep coming up in ML.

Exponents and logs

\(\ln x\) is \(\log_e x\), the natural log. In ML papers and code, plain \(\log\) almost always means \(\ln\) too: np.log, torch.log and math.log are all base \(e\).

exp and log are inverses

\[ e^{\ln x} = x \quad (x \gt 0) \qquad\qquad \ln\!\left(e^{x}\right) = x \]

The same holds for any base \(b\):

\[ b^{\log_b x} = x \qquad\qquad \log_b\!\left(b^{x}\right) = x \]

So \(\log_b x\) answers “what power do I raise \(b\) to, to get \(x\)?”. \(\ln\) is only defined for \(x \gt 0\), and \(e^x \gt 0\) for every \(x\).

Exponent rules

RuleFormula
Product\(a^m \cdot a^n = a^{m+n}\)
Quotient\(\dfrac{a^m}{a^n} = a^{m-n}\)
Power of a power\(\left(a^m\right)^n = a^{mn}\)
Power of a product\((ab)^n = a^n b^n\)
Power of a quotient\(\left(\dfrac{a}{b}\right)^n = \dfrac{a^n}{b^n}\)
Zero power\(a^0 = 1\)
Negative power\(a^{-n} = \dfrac{1}{a^n}\)
Fractional power\(a^{1/n} = \sqrt[n]{a} \qquad a^{m/n} = \sqrt[n]{a^m}\)
With \(e\)\(e^{x+y} = e^x e^y \qquad e^{x-y} = \dfrac{e^x}{e^y}\)

Log rules

Each one is an exponent rule seen through the log. They hold for any base.

RuleFormula
Product\(\log(ab) = \log a + \log b\)
Quotient\(\log\!\left(\dfrac{a}{b}\right) = \log a - \log b\)
Power\(\log\!\left(a^n\right) = n \log a\)
Reciprocal\(\log\!\left(\dfrac{1}{a}\right) = -\log a\)
Log of 1\(\log 1 = 0\)
Change of base\(\log_b x = \dfrac{\ln x}{\ln b}\)
Example: log of a softmax

With \(m = \max_k z_k\), the quotient rule, then \(\ln(e^x) = x\):

\[ \begin{aligned} \ln\!\left(\frac{e^{z_j - m}}{\sum_k e^{z_k - m}}\right) &= \ln\!\left(e^{z_j - m}\right) - \ln \sum_k e^{z_k - m} \\ &= (z_j - m) - \ln \sum_k e^{z_k - m} \end{aligned} \]

No \(e^x\) is ever taken and then logged again, so nothing underflows to \(\ln 0\).

Sums and products

NameFormula
Sum\(\displaystyle\sum_{i=1}^{n} x_i = x_1 + x_2 + \dots + x_n\)
Product\(\displaystyle\prod_{i=1}^{n} x_i = x_1 \cdot x_2 \cdots x_n\)
Constant out\(\displaystyle\sum_i c\,x_i = c \sum_i x_i\)
Split a sum\(\displaystyle\sum_i (x_i + y_i) = \sum_i x_i + \sum_i y_i\)
Sum of a constant\(\displaystyle\sum_{i=1}^{n} c = nc\)
Swap double sums\(\displaystyle\sum_i \sum_j a_{ij} = \sum_j \sum_i a_{ij}\)
Log of a product\(\displaystyle\log \prod_i x_i = \sum_i \log x_i\)
Mean\(\displaystyle\mu = \frac{1}{n}\sum_{i=1}^{n} x_i\)
Variance (biased, ÷n)\(\displaystyle\sigma^2 = \frac{1}{n}\sum_{i=1}^{n} (x_i - \mu)^2 = \frac{1}{n}\sum_{i=1}^{n} x_i^2 - \mu^2\)
Dot product\(\displaystyle a \cdot b = \sum_i a_i b_i\)
Matrix product\(\displaystyle (AB)_{ij} = \sum_k A_{ik} B_{kj}\)
Log-sum-exp\(\displaystyle\log \sum_i e^{x_i} = m + \log \sum_i e^{x_i - m}, \quad m = \max_i x_i\)

Log of a product is why ML works with log-likelihoods: a product of thousands of probabilities underflows to 0, but the sum of their logs is a normal number.

Calculus

Definitions

NameFormula
Derivative\(\displaystyle f'(x) = \frac{df}{dx} = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}\)
Central difference (numerical gradient)\(\displaystyle f'(x) \approx \frac{f(x+h) - f(x-h)}{2h}\)
Notation\(f'(x) \;=\; \dfrac{df}{dx} \;=\; \dfrac{d}{dx} f(x)\)

The derivative is the slope of \(f\) at \(x\): how much \(f\) changes per unit change in \(x\). The central difference is what a gradient check uses, and its error shrinks like \(h^2\) rather than \(h\).

For GELU, \(\Phi\) is the standard normal CDF and \(\phi(x) = \frac{1}{\sqrt{2\pi}} e^{-x^2/2}\) is its PDF. \(\tanh\) and \(\sigma\) have derivatives written in terms of their own output, which is why backprop caches the output for them.

Derivative rules

RuleFormula
Constant multiple\(\bigl(c\,f\bigr)' = c\,f'\)
Sum\((f + g)' = f' + g'\)
Product\((fg)' = f'g + fg'\)
Quotient\(\left(\dfrac{f}{g}\right)' = \dfrac{f'g - fg'}{g^2}\)
Power\(\dfrac{d}{dx} x^n = n x^{n-1}\)
Chain\(\dfrac{d}{dx} f\bigl(g(x)\bigr) = f'\bigl(g(x)\bigr)\, g'(x)\)

Power rule

\[ \frac{d}{dx}\, x^n = n\,x^{n-1} \qquad \text{for any real } n \]

Bring the power down in front, then subtract 1 from the power. Rewrite roots and fractions as powers first, so the rule applies:

\[ \sqrt{x} = x^{1/2} \qquad \frac{1}{x^n} = x^{-n} \qquad \frac{1}{\sqrt{x}} = x^{-1/2} \]
Examples \[ \begin{aligned} \frac{d}{dx}\left(3x^4 - 2x + 7\right) &= 12x^3 - 2 \\[4pt] \frac{d}{dx}\,\frac{1}{x^3} = \frac{d}{dx}\,x^{-3} &= -3x^{-4} = -\frac{3}{x^4} \\[4pt] \frac{d}{dx}\,\sqrt{x} = \frac{d}{dx}\,x^{1/2} &= \tfrac{1}{2}x^{-1/2} = \frac{1}{2\sqrt{x}} \\[4pt] \frac{d}{dv}\,(v + \epsilon)^{-1/2} &= -\tfrac{1}{2}(v + \epsilon)^{-3/2} \end{aligned} \]

The last one (strictly also a chain rule, but the inner derivative is 1) is the variance term in layernorm's backward pass.

Chain rule

\[ \frac{d}{dx}\, f\bigl(g(x)\bigr) = f'\bigl(g(x)\bigr) \cdot g'(x) \]

In Leibniz notation, with \(y = f(u)\) and \(u = g(x)\):

\[ \frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx} \]

How to apply it: name the inner expression \(u\). Differentiate the outer function with respect to \(u\), as if \(u\) were the variable, then multiply by \(du/dx\). For deeper nesting, repeat working inwards: one factor per layer.

Examples

\(e^{3x^2}\), with \(u = 3x^2\):

\[ \frac{d}{dx}\, e^{3x^2} = e^{u} \cdot \frac{du}{dx} = e^{3x^2} \cdot 6x \]

\(\ln(1 + e^x)\), with \(u = 1 + e^x\):

\[ \frac{d}{dx} \ln(1 + e^x) = \frac{1}{u} \cdot e^x = \frac{e^x}{1 + e^x} = \sigma(x) \]

A neuron, \(\tanh(wx + b)\), differentiated with respect to \(w\), with \(u = wx + b\):

\[ \frac{d}{dw} \tanh(wx + b) = \bigl(1 - \tanh^2 u\bigr) \cdot x \]

Three layers deep, \(\sin\bigl(\ln(x^2)\bigr)\):

\[ \frac{d}{dx} \sin\bigl(\ln(x^2)\bigr) = \cos\bigl(\ln(x^2)\bigr) \cdot \frac{1}{x^2} \cdot 2x = \frac{2\cos\bigl(\ln(x^2)\bigr)}{x} \]

Partial derivatives

\(\dfrac{\partial f}{\partial x}\) is the derivative of \(f\) with respect to \(x\), treating every other variable as a constant.

The gradient collects all the partial derivatives. It has the same shape as the input:

\[ \nabla f = \left( \frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, \dots, \frac{\partial f}{\partial x_n} \right) \]
Example: two variables \[ f(x, y) = x^2 y + 3y + \sin x \] \[ \frac{\partial f}{\partial x} = 2xy + \cos x \qquad\qquad \frac{\partial f}{\partial y} = x^2 + 3 \]

For \(\partial f/\partial x\), \(y\) acts like a number, so \(x^2 y\) behaves like \(5x^2\) and \(3y\) is a constant (derivative 0).

Example: squared error \[ L(w, b) = (wx + b - y)^2 \] \[ \frac{\partial L}{\partial w} = 2(wx + b - y) \cdot x \qquad\qquad \frac{\partial L}{\partial b} = 2(wx + b - y) \]

Chain rule on the outside, then the partial of the inside: \(\partial(wx + b - y)/\partial w = x\) and \(\partial(wx + b - y)/\partial b = 1\).

Example: a sum, differentiated by one element \[ f(w) = \sum_i w_i x_i \qquad\Longrightarrow\qquad \frac{\partial f}{\partial w_k} = x_k \]

Only the \(i = k\) term contains \(w_k\); every other term is a constant and drops out. Written with the Kronecker delta, \(\partial w_i / \partial w_k = \delta_{ik}\), which is 1 when \(i = k\) and 0 otherwise, so \(\sum_i \delta_{ik} x_i = x_k\).

Multivariable chain rule

If \(z = f(x, y)\) and both \(x\) and \(y\) depend on \(t\):

\[ \frac{dz}{dt} = \frac{\partial z}{\partial x} \frac{dx}{dt} + \frac{\partial z}{\partial y} \frac{dy}{dt} \]

In general, if \(L\) depends on \(x_i\) through intermediate values \(y_1, \dots, y_m\):

\[ \frac{\partial L}{\partial x_i} = \sum_{j=1}^{m} \frac{\partial L}{\partial y_j} \, \frac{\partial y_j}{\partial x_i} \]

How to apply it: find every path from \(x\) to \(L\). Each path gives one product of derivatives along it (the ordinary chain rule); add the paths together. This is why gradients accumulate with += when a value is used more than once.

“Multivariable chain rule” is the usual name. “Multivariate” means the same thing but is mostly used in statistics.

Example: two paths

\(z = xy\), with \(x = t^2\) and \(y = \sin t\):

\[ \frac{dz}{dt} = \underbrace{y \cdot 2t}_{\text{via } x} + \underbrace{x \cdot \cos t}_{\text{via } y} = 2t \sin t + t^2 \cos t \]

That matches the product rule on \(t^2 \sin t\).

Example: a value used twice \[ L = ab + a \qquad\Longrightarrow\qquad \frac{\partial L}{\partial a} = b + 1 \]

\(a\) reaches \(L\) through the product and directly, so the two contributions add.

Example: a linear layer, \(Y = XW\)

Element-wise, \(Y_{nj} = \sum_k X_{nk} W_{kj}\). Each \(W_{kj}\) reaches \(L\) through every row \(n\) of \(Y\), so sum over \(n\):

\[ \frac{\partial L}{\partial W_{kj}} = \sum_n \frac{\partial L}{\partial Y_{nj}} \frac{\partial Y_{nj}}{\partial W_{kj}} = \sum_n \frac{\partial L}{\partial Y_{nj}} X_{nk} \] \[ \Longrightarrow\quad \frac{\partial L}{\partial W} = X^{\top} \frac{\partial L}{\partial Y} \]

Each \(X_{nk}\) reaches \(L\) through every column \(j\) of row \(n\):

\[ \frac{\partial L}{\partial X_{nk}} = \sum_j \frac{\partial L}{\partial Y_{nj}} W_{kj} \] \[ \Longrightarrow\quad \frac{\partial L}{\partial X} = \frac{\partial L}{\partial Y} W^{\top} \]

In code: dW = x.T @ dout and dx = dout @ W.T.
