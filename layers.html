Layers

The building blocks, one at a time: what each does, what it's for, its derivative, and where the derivative comes from.

Conventions

NotationMeaning
\(x \to y\)The layer's input and output.
\(\dfrac{\partial L}{\partial y}\)Upstream gradient, given to the backward pass. dout in code.
\(\odot\)Element-wise product (* in NumPy).
\(N\)Batch size: rows are examples.

For an element-wise function \(y = f(x)\), the backward pass is always \(\dfrac{\partial L}{\partial x} = \dfrac{\partial L}{\partial y} \odot f'(x)\), so for the activations below only \(f'\) matters.

Linear

\[ y = xW + b \qquad x: N \times D_{\text{in}}, \quad W: D_{\text{in}} \times D_{\text{out}}, \quad b: D_{\text{out}} \]

What it does: each output is a weighted sum of all the inputs, plus a bias. It mixes features together and changes the vector's size.

Used for: almost everything with learnable weights: hidden layers, the q/k/v projections in attention, the output layer that produces logits.

\[ \frac{\partial L}{\partial x} = \frac{\partial L}{\partial y}\, W^\top \qquad \frac{\partial L}{\partial W} = x^\top \frac{\partial L}{\partial y} \qquad \frac{\partial L}{\partial b} = \sum_{n} \frac{\partial L}{\partial y_n} \]

Derivation: \(y_{nj} = \sum_k x_{nk} W_{kj} + b_j\). The \(x\) and \(W\) gradients are the linear layer example on the Math page. \(b_j\) is added to every row \(n\), so it reaches \(L\) through all of them, each with local derivative 1: sum over \(n\).

Cache: \(x\) and \(W\).

Activations

Non-linear functions applied element-wise between linear layers. Without them, a stack of linear layers collapses into a single linear layer (\(xW_1W_2 = xW'\)), however deep it is.

tanh

\[ \tanh x = \frac{e^x - e^{-x}}{e^x + e^{-x}} \qquad \text{range } (-1, 1) \]

What it does: squashes any number into \((-1, 1)\), roughly linear near 0 and flat for large \(|x|\). Centred on zero.

Used for: hidden layers in small and older networks, RNN cells, and inside the tanh approximation of GELU.

\[ \frac{d}{dx}\tanh x = 1 - \tanh^2 x \qquad\Longrightarrow\qquad \frac{\partial L}{\partial x} = \frac{\partial L}{\partial y} \odot (1 - y^2) \]
Derivation

Quotient rule with \(u = e^x - e^{-x}\) and \(v = e^x + e^{-x}\). Note \(u' = v\) and \(v' = u\):

\[ \frac{d}{dx}\frac{u}{v} = \frac{u'v - uv'}{v^2} = \frac{v^2 - u^2}{v^2} = 1 - \left(\frac{u}{v}\right)^2 = 1 - \tanh^2 x \]

Cache: the output \(y\), since the derivative is written in terms of it. Gradients vanish for large \(|x|\), where \(1 - y^2 \approx 0\) (saturation).

Sigmoid

\[ \sigma(x) = \frac{1}{1 + e^{-x}} \qquad \text{range } (0, 1) \]

What it does: squashes any number into \((0, 1)\). \(\sigma(0) = \tfrac12\). It's a shifted, scaled tanh: \(\sigma(x) = \tfrac12\bigl(1 + \tanh(x/2)\bigr)\).

Used for: probabilities of yes/no outcomes (binary classification), and gates that scale something between “off” and “on” (LSTMs, SiLU/SwiGLU).

\[ \sigma'(x) = \sigma(x)\bigl(1 - \sigma(x)\bigr) \qquad\Longrightarrow\qquad \frac{\partial L}{\partial x} = \frac{\partial L}{\partial y} \odot y(1 - y) \]
Derivation

Write \(\sigma = (1 + e^{-x})^{-1}\) and use the chain rule (power rule outside, \(e^{-x}\) inside):

\[ \sigma'(x) = -(1 + e^{-x})^{-2} \cdot \bigl(-e^{-x}\bigr) = \frac{1}{1 + e^{-x}} \cdot \frac{e^{-x}}{1 + e^{-x}} \]

The second factor is \(1 - \sigma(x)\), because \(\dfrac{e^{-x}}{1 + e^{-x}} = \dfrac{(1 + e^{-x}) - 1}{1 + e^{-x}} = 1 - \dfrac{1}{1 + e^{-x}}\).

The maximum slope is \(\tfrac14\) at \(x = 0\), so stacked sigmoids shrink gradients quickly. That's why hidden layers moved to tanh, then ReLU.

ReLU

\[ \operatorname{ReLU}(x) = \max(0, x) \]

What it does: passes positive values through unchanged and zeroes negative ones.

Used for: the default hidden-layer activation for most of the 2010s (CNNs, MLPs). It's cheap, and positive inputs never saturate, so gradients pass through deep stacks undiminished.

\[ \frac{d}{dx}\operatorname{ReLU}(x) = \begin{cases} 1 & x \gt 0 \\ 0 & x \le 0 \end{cases} \qquad\Longrightarrow\qquad \frac{\partial L}{\partial x} = \frac{\partial L}{\partial y} \odot [x \gt 0] \]

Derivation: each piece is linear: slope 1 on the right, slope 0 on the left. The derivative at exactly 0 is undefined; frameworks use 0.

Cache: the mask \(x \gt 0\). A unit whose input is negative for every example gets no gradient at all and never recovers (a “dead” ReLU).

GELU

\[ \operatorname{GELU}(x) = x\,\Phi(x) \qquad \Phi(x) = \tfrac12\Bigl(1 + \operatorname{erf}\bigl(x/\sqrt2\bigr)\Bigr) \]

What it does: a smooth ReLU. \(\Phi\) is the standard normal CDF, which goes smoothly from 0 to 1, so GELU scales each input by “how positive it is”. Large positive inputs pass through, large negative ones go to 0, with a smooth dip just below zero.

Used for: the MLP inside GPT-2, BERT and many other transformers.

\[ \operatorname{GELU}'(x) = \Phi(x) + x\,\phi(x) \qquad \phi(x) = \frac{1}{\sqrt{2\pi}}\, e^{-x^2/2} \]

Derivation: product rule on \(x \cdot \Phi(x)\); the derivative of a CDF is its PDF, \(\Phi' = \phi\).

The tanh approximation, \(\tfrac12 x\bigl(1 + \tanh\bigl(\sqrt{2/\pi}\,(x + 0.044715\,x^3)\bigr)\bigr)\), was used when erf was slow. PyTorch's F.gelu uses the exact form by default; approximate="tanh" gives this one.

Softmax

\[ p_i = \operatorname{softmax}(z)_i = \frac{e^{z_i}}{\sum_k e^{z_k}} \]

What it does: turns a vector of arbitrary scores (logits) into a probability distribution: every \(p_i\) is in \((0, 1)\) and they sum to 1. Bigger scores get exponentially more of the share. Adding the same constant to every \(z_i\) changes nothing.

Used for: the model's output (probabilities over classes or next tokens), and attention weights (how much each position attends to each other position).

Computing it: subtract the row's maximum first, \(p_i = e^{z_i - m} / \sum_k e^{z_k - m}\), so \(e^x\) can't overflow.

Jacobian

Every output depends on every input, through the sum:

\[ \frac{\partial p_i}{\partial z_j} = p_i\,(\delta_{ij} - p_j) = \begin{cases} p_i(1 - p_i) & i = j \\ -p_i\,p_j & i \ne j \end{cases} \]
Derivation

Let \(S = \sum_k e^{z_k}\), so \(p_i = e^{z_i}/S\) and \(\partial S/\partial z_j = e^{z_j}\). Quotient rule:

\[ i = j: \quad \frac{e^{z_i} S - e^{z_i} e^{z_i}}{S^2} = \frac{e^{z_i}}{S} - \left(\frac{e^{z_i}}{S}\right)^2 = p_i - p_i^2 \] \[ i \ne j: \quad \frac{0 \cdot S - e^{z_i} e^{z_j}}{S^2} = -\frac{e^{z_i}}{S}\cdot\frac{e^{z_j}}{S} = -p_i\,p_j \]

Backward pass

\[ \frac{\partial L}{\partial z_j} = p_j \left( \frac{\partial L}{\partial p_j} - \sum_i \frac{\partial L}{\partial p_i}\, p_i \right) \]
Derivation

Multivariable chain rule over every output \(p_i\), then the Jacobian:

\[ \frac{\partial L}{\partial z_j} = \sum_i \frac{\partial L}{\partial p_i}\, p_i(\delta_{ij} - p_j) = \frac{\partial L}{\partial p_j}\, p_j - p_j \sum_i \frac{\partial L}{\partial p_i}\, p_i \]

The \(\delta_{ij}\) picks out the \(i = j\) term from the first part of the sum.

In code, row by row: dz = p * (dp - (dp * p).sum(axis=-1, keepdims=True)). No need to build the \(C \times C\) Jacobian. Cache: the output \(p\).

Losses

The last layer. Its output is a single number, and its backward pass starts the chain with \(\partial L/\partial L = 1\), so it takes no upstream gradient.

Mean squared error

\[ L = \frac{1}{N} \sum_n (\hat{y}_n - y_n)^2 \]

What it does: averages the squared distance between prediction and target. Squaring makes it positive and punishes big misses much more than small ones.

Used for: regression: predicting numbers rather than classes.

\[ \frac{\partial L}{\partial \hat{y}_n} = \frac{2}{N}\,(\hat{y}_n - y_n) \]

Derivation: only the \(n\)-th term contains \(\hat{y}_n\); chain rule on the square gives \(2(\hat{y}_n - y_n)\), times the \(\tfrac1N\) in front.

Softmax + cross-entropy

\[ L = -\frac{1}{N} \sum_n \log p_{n,\,y_n} \qquad p_n = \operatorname{softmax}(z_n) \]

What it does: looks at the probability the model gave the correct class, \(p_{n, y_n}\), and takes \(-\log\) of it. That's 0 when the model is certain and right, and grows without limit as the probability of the right answer goes to 0. Averaged over the batch.

Used for: any classification, including language models, where the classes are the possible next tokens. A model that guesses uniformly over \(C\) classes scores \(\log C\).

Computing it: never take \(\log\) of a probability. Use log-softmax directly:

\[ \log p_{n,\,y_n} = z_{n,\,y_n} - \log \sum_k e^{z_{n,k}} = (z_{n,\,y_n} - m_n) - \log \sum_k e^{z_{n,k} - m_n} \]
\[ \frac{\partial L}{\partial z} = \frac{1}{N}\,(P - Y) \]

\(P\) is the softmax output and \(Y\) the one-hot targets: the probabilities, minus 1 at each correct class, divided by \(N\).

Derivation

For one example, using the log-softmax form with target \(y\):

\[ \ell = -z_y + \log \sum_k e^{z_k} \] \[ \frac{\partial \ell}{\partial z_j} = -\delta_{jy} + \frac{1}{\sum_k e^{z_k}} \cdot e^{z_j} = p_j - \delta_{jy} \]

The first term is 1 only for the target class. The second is the chain rule through the log, then \(\partial/\partial z_j\) of the sum, which picks out \(e^{z_j}\). The mean over \(N\) examples divides each by \(N\).

It's one function returning both the loss and \(\partial L/\partial z\). Going through softmax and log separately gives the same answer, but via the full Jacobian and a \(1/p\) that can blow up; together, everything cancels.
